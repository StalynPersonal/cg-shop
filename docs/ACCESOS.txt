NO usar estas credenciales en producción.


1. CÓMO ARRANCAR
----------------
Portal web (obligatorio):
    cd C:\Users\scontreras\Desktop\mio\cg-shop
    dotnet run --project src/CgShop.Web --launch-profile http

API REST (opcional):
    dotnet run --project src/CgShop.Api --launch-profile http

Esperar el mensaje "Now listening on: http://localhost:5091" y dejar la terminal abierta.

8. NOTAS
--------
- Usar siempre el subdominio (verde.localhost, admin.localhost), no 127.0.0.1:
  la tienda se identifica por el subdominio.
- Cada usuario solo puede iniciar sesión en su propio subdominio
  (admin@verde.local no entra en rojo.localhost).
- Para comprar hay que iniciar sesión o crear una cuenta (el checkout redirige al login).
- Al iniciar sesión: propietario/empleado -> panel /admin ; cliente -> /mi-cuenta
  (o vuelve al checkout si venía de ahí).
- Los pedidos demo antiguos no pertenecen a ningún cliente; los pedidos nuevos
  aparecen en "Mi cuenta" del cliente que los hizo.
- La sesión se cierra tras 15 minutos sin actividad (aviso 1 minuto antes).
  Configurable en src/CgShop.Web/appsettings.json -> "Session": { "IdleTimeoutMinutes": 15 }
- Si el navegador no abre *.localhost, usar *.lvh.me
  (por ejemplo http://verde.lvh.me:5091).
- Las empresas creadas desde el Super Admin quedan en http://<subdominio>.localhost:5091
  con el usuario administrador definido al crearlas.
